This portfolio site has gone through a few iterations as my interest in working with different tech stacks has evolved.

- Started as a self-hosted Eleventy static site for experience with static sites and nunjucks
- Moved hosting to Deno Deploy for experience with Deno and edge deployments after attending a presentation about Deno
- Rewritten with AI assitance for experience in Astro and Starwind UI, and deployed on Cloudflare Workers before Deno Deploy ends (although I'm on the fence about Tailwind still)

## Technical Focus

Each iteration learned about deployments and different ways to write a static site. Now it's also including ways to use orchestration, prompting, and other tools of the modern development workflow.
